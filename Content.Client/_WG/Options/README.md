# Options

The Game Options window has two master tabs above its tabs. **SS14** holds the stock tabs with stock settings only.
**Wolfgate** holds every setting stock SS14 doesn't have, whether Wolfgate's own or from a fork layer (Mono, White
Dream, Goobstation, Delta-V, Far Horizons), in its own tabs: Interface, Chat, Graphics, Audio, Accessibility, Controls
and Consent.

Entry points: `OptionsMenu.Wolfgate.cs` (the master tabs, wired in by a marked edit in `OptionsMenu`),
`WGOptionsMasterStrip` (the switch, styled by `StyleWolfgate.Options.cs`) and `WolfgateOptionsTabs` (the Wolfgate
tabs, in place of Delta-V's `DeltaTab`). A new player-facing client cvar gets a control on one of the `WG*Tab` tabs,
never on a stock tab. A feature's controls go in a partial of that tab named after the feature
(`WGChatTab.SpeechBubbles.cs`), kept here in `UI/Tabs` beside the tab's XAML so its namespace follows its folder.

The Controls tab is split the same way: `KeyRebindTab(true)` on the Wolfgate side lists only the binds and checkboxes
missing from stock SS14 (`KeyRebindTab.Wolfgate.cs` lists the stock ones; anything else is a fork bind), and drops the
section headers left empty on either side. A new keybind lands on the Wolfgate side unless it is added to that stock
list. The Wolfgate Controls tab carries the "Set to SS13 default" button, which resets every keybind and then applies
`Ss13KeybindPreset`, the SS13 hotkey layout for each action that has a counterpart here; Reset all stays on the SS14
side.

The Consent tab holds the OOC consent preferences; the consent keybind opens the options on it
(`OptionsMenu.ConsentTabIndex`). Consent is stored per player on the server, so the tab keeps its own Save button
rather than the shared Apply row.

A search bar above the master tabs (`OptionsSearch`) filters every tab on both sides at once: it hides settings whose
text doesn't contain the query, emptied section headers and tabs with nothing left, and in each tab container whose
current tab has no match moves to the first tab with one, so a Wolfgate-only match found from the SS14 side switches
to the Wolfgate master tab and the right tab. A master tab with no match is greyed out; the others show how many of
their tabs match. A matching section header or tab title keeps the whole section or tab. On the Controls tabs it hands
the query to `KeybindSearch`, which also matches a bound key exactly (typing `W` finds what W is bound to).
