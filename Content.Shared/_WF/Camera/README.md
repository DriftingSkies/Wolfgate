# Camera

Tweaks to how the view moves.

Screen shake: a camera kick (explosions, gravity shakes, impacts, recoil) moves the view at most 0.3 tiles instead of a
full tile. Whatever a kick has past that becomes a short shake in place, faster and longer the harder the kick
(10 to 30 swings a second, up to 0.8 s). The Accessibility tab's screen shake slider still scales it all. Entry point:
`CameraRecoilSystem.WFKickCamera` on the client, called from a marked edit in `CameraRecoilSystem.KickCamera`.

Default to North: an Extra tab option (`wf.eye_default_north`). With it on, stepping onto a grid turns the view to that
grid's north rather than the nearest cardinal to the old view. The cvar is replicated so the server predicts the same
rotation; `WFDefaultNorthSystem.WantsNorth` is read from a marked edit in `SharedMoverController.TryUpdateRelative`.
