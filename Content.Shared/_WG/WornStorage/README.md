# WornStorage

An SS13-style option for worn storage, off by default: Game Options > Wolfgate > Controls > General > "Clicking worn or stored
storage opens it". With it on, left-clicking a worn backpack, belt or other storage in an inventory slot opens it when
the active hand is empty, and a click with an item in hand still puts the item inside. Taking the storage off is a drag from its slot
onto an empty hand; the item goes into that hand, which becomes the active one.

The same option covers storage inside an open storage window, such as a box in a backpack: a click with an empty hand
opens it in place, and taking it out is a drag out of the window, onto an empty hand or anywhere else outside a storage
window. Other stored items, and a click with an item in hand, behave as upstream. Storage that doesn't open on
activation, or a server with `control.nested_storage` off, keeps the upstream click.

Entry points: the client cvar `wg.worn_storage_click_opens` (`WornStorageCVars.ClickOpens`), and the
`InventoryUIController` partial, which `ItemPressed` and each slot button's `Unpressed` call into by marked edits. It
holds the click with a `DragDropHelper` until release, so a press that doesn't move past the drag dead zone is a click.
For stored storage, the `StorageUIController` partial is called from `OnPieceUnpressed`, which already tells a click
from a drag. Everything is client-side and goes through the existing `OpenSlotStorageNetworkMessage`,
`OpenNestedStorageEvent`, `StorageInteractWithItemEvent`, `RequestSetHandEvent` and `UseSlotNetworkMessage`.
