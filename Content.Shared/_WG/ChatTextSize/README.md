# ChatTextSize

The chat log's text size and line spacing: Game Options > Misc > Speech > "Chat text size" (`wg.chat_text_size`, 0 for
the theme's font, at least 8 pt otherwise) and "Chat line spacing" (`wg.chat_line_spacing`, extra pixels). This is the
reader's size for the whole log. The `ChatFont` module's per-character speech fonts are a separate thing.

The engine's `OutputPanel` only takes its font from a style property. So when either setting differs from the theme,
`ChatBox.WgUpdateTextSize` gives the log its own copy of the current stylesheet with one extra rule. That rule sets the
font to Noto Sans at the chosen size, wrapped in `WGSpacedFont` for the extra line height. The copy is rebuilt when
the setting or the UI theme changes, and removed at the defaults, so a default setup is untouched.
