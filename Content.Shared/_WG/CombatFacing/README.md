# CombatFacing

A Misc tab option, **Face the cursor in combat mode** (`wg.combat_face_cursor`, on by default). On, combat mode turns
you toward the mouse as before. Off, combat mode leaves facing alone and you turn by moving.

The cvar is a replicated client cvar, so the server reads each player's choice when they enter combat mode, through
`WGCombatFacingSystem.WantsFaceCursor` from a marked edit in `SharedCombatModeSystem.SetInCombatMode`. Mobs with no
player keep facing the cursor. Flipping the option mid-fight sends `WGCombatFaceCursorChangedEvent`, and the server
adds or removes the mouse rotator then and there, so a stale `NoRotateOnMoveComponent` never stops you turning. A player
who takes over a mob already in combat gets its rotator removed if their option is off; with it on, the mob is left as
it was (an NPC's combat mode adds none) until they toggle combat mode.
