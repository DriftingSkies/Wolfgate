# Currency

Names the sector's money **thalers** (one thaler, two thalers) in place of Monolith's credits and Frontier's spesos.
Only player-facing text changes: prototype IDs (`SpaceCash`, `Credit`, `Speso`), YAML fields such as `spesos:` and
admin console output keep their old names. Counterfeit bills are **thallers**. Prices still show with the `$` symbol
from `BankSystemExtensions.ToSpesoString`.

Strings that print an amount pick `thaler` or `thalers` with a Fluent selector on the number, so the argument must be
the number itself, not a preformatted string.
