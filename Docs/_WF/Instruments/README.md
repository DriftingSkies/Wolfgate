# Instruments

Wizden's instrument UI overhaul (wizden#41604) and its MIDI file collection (wizden#44469), ported ahead of
Monolith. The instrument window shows the instrument and splits playback into Files, Band and Input panels, with a
Configuration tab for channels. Files are kept in the user data `UserMidis` folder, where players can also drop MIDIs
by hand; the Files panel adds, renames, removes, filters and shuffles them.

Differences from upstream: channel toggles use a `CheckBox` (upstream's `SwitchButton`, wizden#39161, isn't here),
and upstream's `StyleClass.Negative` is `StyleBase.ButtonCaution` here. The old `BandMenu` and
`ChannelsMenu` are deleted as upstream did. When Monolith brings the overhaul in, take upstream's files and drop
the markers.

Follow-ups included: wizden#41272 (MIDI input min volume slider; the server also checks the sender is the player,
which upstream doesn't), #45055 (percussion channel fix, one-based channel numbers) and #46033 (channels panel fills
the window). UI files match wizden 2d25896763.
