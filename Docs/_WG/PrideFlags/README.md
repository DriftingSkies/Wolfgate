# PrideFlags

Twelve wall-hung pride flags to go with upstream's rainbow `LGBTQFlag`: gay, lesbian, bisexual, transgender, pansexual,
asexual, aromantic, nonbinary, genderfluid, agender, genderqueer and intersex (`WGPrideFlag*`, `flags.yml`). They hang
like any wall flag. The Lupercal flies them in its public rooms (its generator's `crewlife.PRIDE_ROOMS`).

The sprites are drawn by `Tools/_WG/PrideFlags/pride_flags.py` from the rainbow flag: each cloth pixel keeps its place
in the drape and its shading, and takes the new flag's stripe colour there, so every flag folds as the rainbow one
does. Rerun it to change a flag or add one; the states and `meta.json` are rewritten.
