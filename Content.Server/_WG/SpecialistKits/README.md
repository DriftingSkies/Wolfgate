# SpecialistKits

A specialist rack at the Halcyon (in the marines' bunk room) and at Helios (by the Vanguard outfitters) hands each
player one free kit per round, from RMC's automated vendor. Each kit is a role: armor with its specialization, a
weapon and the tools for the job.

| Role | TSF | PDV |
|---|---|---|
| Breach | Breacher | Boarder |
| Engineer (job) | Combat Engineer (Engineer) | Artificer (Artificer) |
| Medic (job) | Corpsman (Corpsman) | Field Medic (Jarrah) |
| Long range | Marksman | Sharpshooter |
| Fire | Pyrotechnician | Burner |
| Scout | Recon | Akıncı Raider |
| Heavy (job) | Heavy Gunner (Fireteam Leader) | Heavy (Denasvar) |
| Ship crew | Ship Gunner | Topçu |

Job kits are held to their job. Open kits are limited per faction: 1, plus 1 for every 10 members online, up to 3 a
round. RMC's own `sharedSpecLimit` counts by entry position across every specialist vendor, so it would mix the two
factions' kits; the limit is checked instead on `WGSpecialistKitVendAttemptEvent`, which a marked hook in
`SharedCMAutomatedVendorSystem` raises. RMC's vendor UI shows section names as written, so the one section name is
plain English.

Entry points: `WGSpecialistKitSystem`, `WGSpecialistKitComponent` on each kit's vendor bundle, and
`Resources/Prototypes/_WG/SpecialistKits` (kits, vendors).
