# Shrines

One otherworldly shrine per world, placed by the planet POI tables as an isolated site with no road to it.

- **Carcinoma, Fountain of Life** (`WGFountainOfLife`): holds 30u of vitae (`WGVitae`) a round, which can't be
  made or bought. Draw it with any container. Ten units in the blood heal everything a rejuvenate does (damage,
  wounds, organs, lost limbs, blood, pain) through `WGLifeSurge`, which puts handcuffs back on afterwards. Less than
  a dose waits for more. The heart stops beating once the fountain is dry (`WGFountainSystem`).

The sprite is drawn by `Tools/_WG/Shrines/fountain_of_life.py`. The site map is hand-made,
`Resources/Maps/_WG/PlanetPois/carcinoma_fountain_of_life.yml`: edit it in game with `loadgrid` and `savegrid`.
