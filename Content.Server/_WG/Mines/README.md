# Mines

Armable mines. `WGLandMineExplosive` is a safe item until a player uses it on a clear floor tile next to them: after a
short do-after it is set (anchored), and it arms a few seconds later, when its sprite starts blinking. A tile with a
wall, another mine or anyone standing on it is refused. An armed mine warns whoever steps on it and explodes when
they step off. Anyone with a multitool (the `Pulsing` tool quality) can disarm a set mine back into an item, even
while someone is standing on it. A set mine knocked loose, such as by prying up its floor, becomes a safe item.

The upstream `LandMineExplosive` is unchanged: always live and never an item. This mine is sold on both faction
uplinks and comes in the PDV Artificer's specialist kit.

Entry points: `WGArmableMineComponent` (delays, tool quality, sounds), `WGArmableMineSystem` (set, arm, disarm,
examine, step-trigger gate) and `WGMineTriggerSystem` (server: the warning and the detonation). The mine handles its
own step-trigger events rather than using the upstream `LandMine` component, because the step trigger still reports
stepping off after a disarm.
