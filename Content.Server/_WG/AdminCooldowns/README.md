# AdminCooldowns

Active admins (not deadminned) skip the cooldowns on upstream player requests: comms console announcements, news
publishing, fax send and copy, holopad emergency broadcasts and bounty contract posts. Each request handler asks
`WGAdminCooldownSystem.Skips(actor)` before refusing, and the client enables the matching button for an admin through
`IClientAdminManager.IsActive()`. The cooldown still starts after an admin's request, so players wait as before.

Wolfgate modules with their own request cooldowns (Boombox, ShipPa, Hailing, Feedback, Unstuck, Respawn) check
`IAdminManager.IsAdmin` themselves.
