# PdaUi

The PDA operating-system look, adapted from /tg/station's modular-computer UI and rebuilt with XAML controls in
Wolfgate's retro style. The window is a warm charcoal surface with amber readouts, a textured title plate (amber paw
mark, page title, close), a status header (shift clock, OS name, alert chip, flashlight, ID/pen/pAI/disk eject,
close-program, minimise), a Main/Info/Settings navigation strip, a details panel, the program table, a footer with the
device address, and a settings page. The window can be dragged at any point and resized from its edges. Section
headers use the amber underline, details are compact single-line rows and program rows show a unified icon set,
install status, a Remove/Install action and a RUNNING mark for the hosted program. Device body colours from
`PdaBorderColorComponent` still paint the frame, header underline and left strip.

The main page keeps the owner, assignment and balance; station, alert level, alert advice, war level, shift time,
date and registered ship live on the Info page. Header, navigation and title-bar glyphs come from the same rendered
icon set, so every button has the same visual weight.

Entry points: `PdaOsWindow` (frame, title bar and chrome), `PdaOsMenu` (views and state), `PdaHeaderBar`, the shared
controls (`PdaSection`, `PdaInfoRow`, `PdaProgramRow`, `PdaSettingsRow`, `PdaButton`, `PdaIconButton`), `PdaPalette`
(Wolfgate Retro colours and fonts), `PdaIcons` (chrome glyphs), `PdaProgramIcons` (program icon set), `PdaAppTheme` (stock
control classes for cartridge UIs) and `PdaNotificationsSystem` (program notification toggle).
`PdaBoundUserInterface` is the only upstream file that changed: it opens `PdaOsMenu`, applies `PdaAppTheme` to
attached fragments and offers the notification toggle.

The cartridge contract is unchanged: every program keeps its `UIFragment` and server system, so new cartridges only
need a `programName` and, for a unified icon, an entry in `PdaProgramIcons`.

## Assets

`Resources/Textures/_WG/PdaUi/program_icons.rsi` and `ui_icons.rsi` are rendered from the Font Awesome 6 Free solid
face. A BYOND `.dmi` is not involved: the source UI names icons as font glyphs, so they were rasterised to RSI
states. The title mark is the `paw` glyph in `ui_icons.rsi`, tinted by the window; the font itself is not committed
(SIL OFL 1.1) and the RSI metadata records the CC BY 4.0 attribution.
