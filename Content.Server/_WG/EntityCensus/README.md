# EntityCensus

Says what the server's entities are, so a count that climbs through a round can be traced to what is spawning.

`WGEntityCensusSystem` counts every entity every `wg.census.interval` seconds (300; 0 turns it off), spending at most
`wg.census.budget_ms` (0.5) a tick, so a count of 800,000 takes a few seconds of ticks and no hitch. Each entity is
filed by where it is (`WGCensusKind`: station, player ship, NPC ship, asteroid, other grid, planet, loose in space,
nullspace), whether it is paused, and its prototype. Deletions are tallied as they happen, so each census also gives
how many of each prototype spawned and were deleted since the one before.

- Gauges: `wg_entities{kind, state}`, `wg_entities_prototype{prototype}` and
  `wg_entities_spawned_per_minute{prototype}` (the top 40 of each).
- Log: two `Entity census` lines per count, the totals by place and the 15 prototypes spawned most.
- Console: `wg_entcensus [now] [rows]` (Debug flag) prints the last count: place, prototypes, largest grids, spawns.
  `now` counts everything in one tick.

Other systems read `WGEntityCensusSystem.Last`.
