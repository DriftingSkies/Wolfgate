# ShipFacing

Starsector-style helm turning. While piloting, hold **Shift** (`WGShuttleFaceCursor`, rebindable under Shuttle in the
controls) and the ship turns its nose toward the cursor, brakes its turn and holds the heading as the cursor moves.
The cursor counts over the world view or the helm's radar; over any other control the last point stands. A turn key
(Q/E) held at the same time overrides it, and strafing, thrust and braking work as usual. In the cockpit, armed
guns stay aimed while it is held and a Shift+click fires them (`WGCockpitFireInput` reads `Held`).

The client's `WGShipFacingSystem` sends the world point under the cursor (`WGShipFacingTargetEvent`) while the key
is held, at most every 0.05 s as it moves and every 0.25 s while it doesn't, and a null when it is let go. The
server keeps it on the pilot as `WGShipFacingComponent`, which lapses after 0.75 s without a resend or once the
pilot leaves that helm. `MoverController.WgFaceCursor`, called from the helm's input in `OnPilotGetInputs`,
replaces the turn input with `WGShipFacingSteering.TurnInput`: the fastest turn rate that can still brake to a stop
on the heading with the hull's actual gyroscope acceleration (so shields and lost gyros slow it as they slow Q/E),
eased into a proportional finish.

The camera and the helm radar turn with the ship, which makes a still cursor a point on the hull that the nose never
reaches, so the ship chased it. While the key is held at a helm they stand still instead (`WGHeldAngle`, through
`EyeLerpingSystem.WgFacingRotation` and `ShuttleNavControl.WgFacingRotation`): the ship turns on screen, as in
Starsector, and the cursor marks a fixed point. Let go, they swing back to the ship's heading in 0.35 s.
