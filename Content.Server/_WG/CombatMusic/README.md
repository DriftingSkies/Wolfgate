# CombatMusic

Lets each character pick their own combat music, ported from Paragon Moon's combat music system.

Players tick tracks in the **Combat music** tab of the character editor, where each track has a Listen button. When
the character turns on combat mode, one ticked track plays at random. When it ends, another follows for as long as
combat mode stays on, and every ticked track plays before any repeats. Ticking none keeps the faction's own combat
music, which now shuffles and continues the same way rather than going quiet after one track.

The playlist is saved on the profile (`combat_music`, comma-separated `wgCombatTrack` ids). On spawn,
`WGCombatMusicSystem` copies it onto the body as `WGCombatMusicComponent`, which is sent only to its owner. The client
side is a `ContentAudioSystem` partial hooked into the Crescent ambient music system with two marked lines.

To add a track, drop the `.ogg` in `Resources/Audio/_WG/CombatMusic`, credit it in that folder's `attributions.yml`,
and add a `wgCombatTrack` prototype plus its three strings.
