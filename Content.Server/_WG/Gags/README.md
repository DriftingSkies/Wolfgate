# Gags

Recolourable items, after SS13's greyscale sprites (GAGS). An item with the `WGGags` component lists one colour
per slot; every sprite layer whose state ends in `-c<N>` is tinted with colour N on the item, on the wearer and in
hand. The prototype's colours are the defaults, and each layer also carries its default `color`, so the item looks
right before the component has run.

Players recolour an item in the loadout window: a pick that is recolourable shows a swatch per colour in the
strip under the grid, and a reset button. The colours are saved with the loadout (`profile_loadout.gags_colors`),
shown on the character preview, and put on the item when the loadout spawns it.

ClothesMate and AutoDrobe also let players select colours for a recolourable product before confirming its
purchase. The server applies those colours only after the normal vending authorization and purchase checks.
Purchased products can be returned to their original vendor to restore one stock count; the returned entity is
removed, so the next customer receives a fresh item and can choose different colours. Returns restore stock but
do not refund the original purchase.

Entry points: `WGGagsComponent`, `SharedWGGagsSystem` (`SetColors`, `ApplyLoadout`), the client `WGGagsSystem`
that tints, `WGGagsColorRow` (the loadout window's swatches) and `WGGagsColors` (saving and checking colours). The
MeridianClothing module is where the recolourable items come from.
