# ChatWebhook

Copies dead chat and LOOC to Discord channels through plain webhooks, one way. Set `wf.discord.dead_chat_webhook` and/or
`wf.discord.looc_webhook` to a webhook URL (Channel settings, Integrations, Webhooks); leave one empty to turn that
channel off. Messages post under the sender's `Character (username)` and never ping anyone. This is separate from the
bot-based dead chat link in `DiscordChatLink`, which is two-way and needs a bot token.

Entry points: `ChatWebhookSystem`, which listens for `ChatWebhookEvent`, raised from `ChatSystem.SendDeadChat` and
`ChatSystem.SendLOOC`.
