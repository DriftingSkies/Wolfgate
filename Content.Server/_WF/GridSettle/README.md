# GridSettle

Brings idle grids to rest. The engine sends every map and grid to every client, so a drifting wreck or an abandoned
ship costs every player bandwidth each tick until its body sleeps; enough of them starve the client's state buffer
and the game jitters.

Once a second `WFGridSettleSystem` marks a dynamic grid with `WFGridSettleComponent` when nothing in its jointed group
(docks, tethers) has a player aboard, a piloted shuttle console or firing thrusters. A marked grid gets 10x its space
friction and is put to sleep once it is nearly still. Grids in FTL or planet flight are left alone.
