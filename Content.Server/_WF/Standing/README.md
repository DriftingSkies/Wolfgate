# Standing

Fixes to the lying down and knockdown code ported from White Dream (`_White/Standing`). A knocked-down body gets up by
itself when its own player has "auto get up" on in the controls options, and a body with no player (an NPC, somebody
who left) always does. Upstream let every client that saw a knockdown write its own setting on the body.

Entry points: `AutoGetUpSystem` sets `LayingDownComponent.AutoGetUp` on the server when the knockdown starts and when
a player takes or leaves the body; `SharedStunSystem` reads it when the knockdown ends.
