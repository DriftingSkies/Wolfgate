# MarkingToggles

Lets a player show or hide their own markings mid-round. Right-click yourself and pick **Markings**: the window has
a box for each species marking (hair, tail, ears, patterns...) and each custom marking the body wears. Unticked ones
stop being drawn for everyone until they are ticked again or the character is next loaded; nothing is saved to the
character. The player has to be conscious to change them.

Species markings use the upstream `Marking.Visible` flag, which the client already draws by. Custom markings are
listed in `HumanoidAppearanceComponent.HiddenCustomMarkings`, which the CustomMarkings client system skips.

Entry points: the server `MarkingToggleSystem` (checks and applies the requests) and the client
`MarkingToggleSystem` and `MarkingToggleWindow` (verb and window).
