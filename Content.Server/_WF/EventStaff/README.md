# EventStaff

Event staff: a separate `EVENT` admin flag for staff who run events and handle gameplay problems without full
admin powers.

Event chat is a staff channel only `EVENT` holders see and send. Pick **Event** in the chat channel selector, prefix a
message with `{`, or use `esay <text>`. It is kept out of replays like admin chat.

Ahelps are split into **Player issue** and **Gameplay issue**. Players pick the topic at the top of the ahelp window
(Player issue by default); their latest message sets it. Admins with `ADMINHELP` get both as before. `EVENT` holders
get the staff ahelp window and receive and answer only gameplay ahelps; they can also open a new ahelp with a player
who has none, which makes it a gameplay one. Every ahelp line, in game and on Discord, is tagged `(GAMEPLAY)` or
`(PLAYER)`. Categories reset at round restart.

Admin chat and admin alerts now go only to `ADMINCHAT` holders (the client already hid them from everyone else), so
an event-only rank never receives them.

Entry points: `AdminFlags.Event`, `EventChatCommand` (`esay`), `ChatManager.SendEventChat`, and the
`BwoinkSystem` partial with its routing rules in `EventStaffAHelpRules`.
